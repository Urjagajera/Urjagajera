A full-stack web application that enables personalized nutrition and fitness management through health assessments, AI-assisted diet recommendations, progress tracking, and role-based access control. Designed for both users and nutritionists, the platform streamlines client management, wellness monitoring, and personalized diet planning through a secure and responsive interface.

**Tech Stack:** Flask, Python, SQLAlchemy, MySQL, HTML5, CSS3, Bootstrap, Jinja2, Flask-Login, Flask-WTF, Chart.js

## Strux: AI Personal Operating System

A full-stack AI productivity platform designed to unify intelligent assistance, task management, habit tracking, and personal organization into a single workspace. Built with a dual-AI architecture featuring persistent memory, automated task extraction, productivity analytics, and secure authentication to help users plan, organize, and achieve their goals more effectively.

**Tech Stack:** Next.js 16, TypeScript, Tailwind CSS, PostgreSQL (Supabase), NextAuth.js, Groq API (Llama 3.3), Vercel
